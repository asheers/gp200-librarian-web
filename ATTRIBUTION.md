## Upstream credits carried through

donpark's code credits the following, and so do we:

- **GP200 Studio** (Kabir S. Tamari, <https://github.com/kabir0st/gp200-studio>,
  GPL-3.0). It reverse-engineered the SysEx message formats (read request,
  identity query, chunk offsets, nibble encoding), the `.prst` layout, the
  dump-to-file shift of 0x28 and the User-IR model-code range, from USB
  captures of Valeton's own editor.
- **RigSheet** (<https://github.com/ricardo-mv/rigsheet>, all rights
  reserved). donpark used it as an independent cross-check of protocol
  *facts*, such as the SnapTone/NAM code ranges. **No RigSheet code or text is
  used**, by donpark or by us.

## Facts and test vectors from GP200 Studio

GP200 Studio (<https://github.com/kabir0st/gp200-studio>, `src/core/SysExCodec.ts`
@ `7d534c2`, GPL-3.0). `tests/write-guard.test.js` rebuilds its native
patch-move, move-commit, save-commit and author-name frames from that file's
documented layouts. They exist **only so the guard can be shown to refuse
them**; no code under `src/` builds them.

## Bundled fonts (redesign V1)

The interface bundles three typefaces in `assets/fonts/` (WOFF2, Latin
subset, as served by Google Fonts on 2026-11-01), so the app loads no font
from the network. All three are under the **SIL Open Font License 1.1**; the
licence text sits beside the files. The OFL allows bundling with software of
any licence, including GPL-3.0; the fonts stay under the OFL and are not
relicensed.

| Font | Files | Copyright | Licence file |
|---|---|---|---|
| Atkinson Hyperlegible (400, 400 italic, 700) | `atkinson-hyperlegible-*.woff2` | 2020 Braille Institute of America, Inc. | `OFL-AtkinsonHyperlegible.txt` |
| Barlow Condensed (600, 700) | `barlow-condensed-*.woff2` | 2017 The Barlow Project Authors | `OFL-BarlowCondensed.txt` |
| JetBrains Mono (400) | `jetbrains-mono-400.woff2` | 2020 The JetBrains Mono Project Authors | `OFL-JetBrainsMono.txt` |

The visual direction ("amp room") was inspired by the look of Rudy
Widmer's GP200 Studio web app. No code, assets or styles were taken from it.

## Not reused

- Nothing from RigSheet (its licence does not allow derivatives).
- No UI code from any project. `src/ui/` is our own.
- Our own, not adapted: the write guard (`write-guard.js`), copy/Undo and
  verification (`copy.js`), the read-volatile classifier (`volatile.js`),
  the journal (`journal.js`, `src/ui/journal-idb.js`), and, from Phase 3
  S0, the state-evidence register (`state-evidence.js`), the SHA-256
  implementation (`sha256.js`), the name scan (`names.js`) and default
  detection (`defaults.js`). donpark's
  restore, upload-orchestration and fast-pacing code is not used.
